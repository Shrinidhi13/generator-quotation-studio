Bundled quotation fonts
======================

Prepared: 2026-10-10
Static instancing tool: fontTools 4.66.1

These TrueType files are complete, fully static instances made from the official
Google Fonts variable-font sources below. All axes were pinned. FontTools used
instantiateVariableFont(source, {'wght': weight}, updateFontNames=True).
The original family names are retained; standard instance style/PostScript names
are selected from the upstream STAT metadata. Embedded copyright and license
notices are preserved without modification. No glyph outlines were redesigned.

Both families are licensed under SIL Open Font License 1.1. The full upstream
licenses accompany these fonts as Manrope-OFL.txt and SpaceGrotesk-OFL.txt.
The application may bundle these fonts and embed/subset them in generated
quotation PDFs. Keep the license files with any redistributed font files.

Intended application use:
- Manrope-Regular.ttf: body text and table values (weight 400).
- Manrope-Semibold.ttf: labels and table headings (weight 600).
- SpaceGrotesk-Medium.ttf: display headings and numerals (weight 500).
- SpaceGrotesk-Bold.ttf: quotation titles and prominent totals (weight 700).
